# 农大食光 · 校园食堂助手

这是一个可离线打开的单文件网页 APP 原型，面向中国农业大学校园食堂场景。

## 使用方法

1. 解压 `cau-campus-food-app.zip`。
2. 用浏览器打开 `cau-campus-food-app.html`。
3. 首次使用有 10 个积分；排队情报上报可得 1 分，营养详情查询和个性化推荐各消耗 1 分。

无需安装依赖或启动服务器。积分、饮食记录、已解锁的营养详情、排队上报和点评保存在当前浏览器的本地存储中。

## 功能

- **排队情报**：按食堂筛选窗口，选择预计等候时间并上报。
- **菜品营养**：浏览示例菜品，使用积分查看热量、蛋白质、脂肪和碳水估算。
- **饮食推荐**：按均衡、健身高蛋白、减脂轻盈、健康清淡或素食目标，抽取主菜、主食、蔬菜和汤品组合；保存已吃记录，后续推荐会尽量避开最近吃过的菜。
- **点评排行**：浏览示例点评、投票、发布评分和文字点评。
- **低碳账单**：按餐食类型和份数估算碳排，作为辅助参考。

## 原型数据说明

窗口、菜单、营养、评分、点评和碳排因子均为演示数据，不代表食堂实时供应、检测结果或官方评分。真实上线前仍需接入并校验食堂菜单与营养档案、现场排队信息，以及校园账号和内容审核服务。

本原型不提供医疗或营养诊断建议。营养数值与碳排估算仅供参考。
