# 作品展示与拉票

## 先明确规则

- 初赛作品在 ANS 作品墙公开展示，**初赛截止（11/22 18:00）后**开放公众投票。
- 有效票数最高的作品 +20 分，其余按票数比例加分；同分时先比完成度、再比契合度。
- **只认站内真实用户的有效票**。异常高频、小号刷票会直接清零；严重刷票取消附加分资格。
- 现场观众贴纸投票只用于人气奖，不参与初赛分数。

所以拉票的目标只有一个：**在 11/23–11/25 评审窗口内，让尽量多真实同学打开作品墙、看一眼、投票**。

## 不要做的事

- 不买票、不用脚本、不批量注册小号——规则明确会清零甚至取消资格。
- 不在多个群重复刷同一条链接（容易被折叠，也显得不真诚）。
- 不承诺「投票抽奖」之类的诱导，容易违反平台规则。
- 不在作品简介里写无法核实的宣传语（「首个」「唯一」「颠覆」）。
