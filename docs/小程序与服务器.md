# 微信小程序与服务端部署

## 架构

```text
微信小程序（miniprogram/）──┐
                            ├── HTTP/JSON ──→ Node 服务（server.js，端口 3000）
网页版（public/）────────────┘                     │
                                                   ├─ data/menu.json（菜品，只读）
                                                   └─ data/db.json（点评 / 排队，可写）
```

小程序和网页共用同一套后端接口，数据和排队、点评是同一份。

## 一、把小程序跑起来

### 1. 安装工具

安装「微信开发者工具」稳定版（官网下载）。需要微信扫码登录才能使用。

### 2. 导入项目

- 打开开发者工具 → 导入项目
- 目录选择 **仓库根目录** `ganfan-radar`（`project.config.json` 里已指定 `miniprogramRoot: "miniprogram/"`）
- AppID：
  - 有自己的小程序 AppID 就填自己的
  - 没有就选「测试号 / 游客模式」（当前 `project.config.json` 里是 `touristappid`）

### 3. 关闭域名校验（开发期）

开发者工具右上角「详情」→「本地设置」→ 勾选：

> 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

### 4. 启动后端

```bash
cd ganfan-radar
node server.js
```

### 5. 设置服务器地址

小程序首页右上角 **⚙** → 填服务器地址：

| 场景 | 地址 |
|---|---|
| 开发者工具模拟器 | `http://localhost:3000` |
| 手机真机预览（同一 Wi-Fi） | `http://<电脑IPv4>:3000`（`ipconfig` 查看） |
| 线上 | `https://api.你的域名.com` |

地址会存在本地，之后不用重复填。

### 6. 真机预览

- 开发者工具点「预览」，手机微信扫码
- 手机与电脑必须在同一局域网
- 若提示域名不合法：在手机上打开「开发调试」→ 打开调试后再重新进入；不同微信版本表现不同，最稳的方式是配置正式 HTTPS 域名（见第三节）

## 二、服务端部署

### A. 本机运行（已验证）

```bash
node server.js
# 或 Windows 双击 start.bat
```

- 默认端口 3000，`PORT=8080 node server.js` 可改
- 运行数据在 `data/db.json`
- 零依赖，不需要 `npm install`

### B. Docker（推荐上云）

```bash
cd ganfan-radar
docker compose -f deploy/docker-compose.yml up -d --build
```

- 容器内 `DB_FILE=/app/runtime/db.json`，挂载命名卷 `nongcanguan-data`，重建容器不丢点评和排队
- 只把 3000 端口暴露给 127.0.0.1 或内网，公网通过 Nginx 反代
- 设置管理员口令：取消 compose 里 `ADMIN_CODE` 的注释

### C. 裸机 + systemd

```bash
# 1. 放代码
sudo mkdir -p /opt/nongcanguan /var/lib/nongcanguan
sudo cp -r server.js package.json public data/menu.json /opt/nongcanguan/
sudo chown -R www-data:www-data /opt/nongcanguan /var/lib/nongcanguan

# 2. 安装服务
sudo cp deploy/nongcanguan.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now nongcanguan

# 3. 检查
curl http://127.0.0.1:3000/api/health
```

要求 Node 18+，路径按实际安装位置调整 `ExecStart`。

### D. Nginx + HTTPS

```bash
sudo apt install nginx certbot python3-certbot-nginx
sudo cp deploy/nginx.conf /etc/nginx/sites-available/nongcanguan
# 把 api.example.com 改成你的域名
sudo ln -s /etc/nginx/sites-available/nongcanguan /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d api.example.com
```

云厂商安全组只放行 **80 / 443**，不要直接暴露 3000。

## 三、微信平台的硬性要求（重要）

小程序调用 `wx.request` 时，域名必须满足：

1. **HTTPS**（TLS 1.2+），不能用 IP、localhost 或自签证书
2. 域名已在 **小程序后台 → 开发管理 → 开发设置 → 服务器域名** 中加入 request 合法域名
3. 中国大陆主体的域名需要 **ICP 备案**（个人备案通常需要数个工作日，企业类似）

这意味着：

- **比赛期间**：用开发者工具 + 「不校验合法域名」，或真机预览的调试模式演示
- **正式上线**：必须准备已备案域名 + HTTPS 证书 + 后台配置域名，微信审核通过后才能给所有人用
- 小程序注册（微信公众平台，个人主体可用邮箱 + 身份验证）与域名备案是两条独立的流程，都需要时间

如果希望完全绕开域名，可以改用**微信云开发**（云函数 + 云数据库，免域名），但需要把 `server.js` 的接口改写成云函数，本次没有做。

## 四、环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `DB_FILE` | `data/db.json` | 运行数据（点评 / 排队）路径；容器里指向挂载卷 |
| `MENU_FILE` | `data/menu.json` | 菜品数据路径 |
| `ADMIN_CODE` | 空 | 设置后，`POST /api/menu` 需要管理员口令 |

## 五、数据与安全

- **备份**：定期复制 `data/db.json` 或 Docker 卷 `nongcanguan-data`
- **重置**：停止服务，删除 `db.json`，重启即可清空点评和排队
- **公网开放前**：
  - 设置 `ADMIN_CODE`，避免任何人通过接口加菜
  - 目前的限流按设备标识，无法抵御恶意换设备；正式运营需要账号体系与内容审核
  - 建议只让校内用户使用，或加一层访问控制

## 六、演示建议

| 场景 | 推荐方式 |
|---|---|
| 录作品视频 | 开发者工具模拟器 + 网页版并排，画面稳定 |
| 决赛现场试玩 | 笔记本跑服务，手机连同一 Wi-Fi，小程序填局域网 IP |
| 评委远程体验 | 网页版公网地址（Nginx + 域名）最稳；小程序需要体验版 + 调试模式 |
