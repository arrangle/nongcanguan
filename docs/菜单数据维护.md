# 菜单数据维护

所有菜品数据在 [data/menu.json](../data/menu.json)。改完**重启服务**即可生效，不需要改代码。

## 结构

```json
{
  "version": 1,
  "title": "食刻 · 农大智慧餐厅",
  "canteens": [
    { "id": "gong1", "name": "公一食堂", "alias": "公寓一食堂", "status": "online" }
  ],
  "windows": [
    {
      "id": "w18",
      "canteenId": "gong1",
      "number": "18",
      "name": "低脂美食新风尚",
      "short": "轻食 · 营养公示",
      "cover": "assets/photos/04.webp",
      "gallery": ["04", "03"],
      "position": "center 46%",
      "description": "窗口简介，一句话",
      "dishes": [ /* 见下 */ ]
    }
  ],
  "photos": [
    { "id": "04", "caption": "窗口 18 · 低脂菜品每100克营养公示表", "src": "assets/photos/04.webp" }
  ]
}
```

## 菜品字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | 字符串 | 全局唯一，建议 `窗口id-序号`，如 `w18-1`。点评和排队都靠它关联，**上线后不要改** |
| `name` | 字符串 | 菜名，≤30 字 |
| `price` | 数字或 `null` | 元；时价填 `null` |
| `unit` | 字符串 | `/份`、`/个`、`时价` |
| `kcal` | 数字 | **每 100 克**的热量，不是一份 |
| `protein` / `fat` / `carbs` / `fiber` | 数字 | **每 100 克**的克数 |
| `serving` | 数字 | 参考一份的克数，用于换算 |
| `icon` | 字符串 | `leaf` / `noodles` / `meat` / `rice` / `egg` / `bowl` |
| `labels` | 字符串数组 | 如 `["高蛋白", "微辣"]`，用于筛选与配餐分类 |
| `description` | 字符串 | ≤120 字，写口感和份量 |
| `source` | 字符串 | `窗口公示` 或 `AI估算`，会显示在卡片右上角 |

**热量口径务必统一为「每 100 克」**。一份的实际热量由 `kcal × serving ÷ 100` 计算。

## 新增一个窗口

1. 在 `windows` 数组里加一个对象，`id` 唯一（如 `w30`），`number` 是窗口号。
2. `cover` 指向 `public/assets/photos/` 下的照片；没有照片时可以先复用同食堂的照片。
3. `gallery` 是照片 id 数组，对应 `photos` 里的 `id`。
4. 加菜品时 `serving` 必填，否则按 250g 计。

## 新增照片

1. 把图片放到 `public/assets/photos/`，命名如 `15.webp`（建议 WebP，宽 1600 左右）。
2. 在 `photos` 数组里加 `{ "id": "15", "caption": "窗口 XX · 说明", "src": "assets/photos/15.webp" }`。
3. 在对应窗口的 `gallery` 里追加 `"15"`。

## 校验与生效

```bash
node -e "JSON.parse(require('fs').readFileSync('data/menu.json','utf8')); console.log('JSON OK')"
node server.js
```

启动日志会打印「窗口 N 个 · 菜品 M 道 · 照片 K 张」。如果数字不对，说明 JSON 结构被改坏了。

## 通过接口追加菜品（可选）

设置 `ADMIN_CODE` 后启动：

```bash
ADMIN_CODE=your-code node server.js
```

```bash
curl -X POST http://localhost:3000/api/menu \
  -H "Content-Type: application/json" \
  -d '{"windowId":"w18","name":"清炒时蔬","price":5,"kcal":45,"protein":2.1,"fat":2.0,"carbs":4.8,"fiber":1.6,"serving":200,"icon":"leaf","labels":["素食"],"description":"当季蔬菜清炒","adminCode":"your-code"}'
```

接口会把新菜写回 `data/menu.json`。改动前建议先备份这份文件。

## 数据修改的诚实原则

- 从现场公示表抄来的数值，`source` 写「窗口公示」。
- 按菜名估算的，写「AI估算」。
- 不要把估算标成公示，也不要为了好看改低热量。
