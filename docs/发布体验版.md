# 发布体验版（发给别人用）

小程序和网页不一样：**预览二维码只有开发者本人能扫**。要让别人在自己微信里打开，必须走「体验版 + 体验成员」。

## 前提：一个正式的小程序 AppID

- 当前项目用的是开发者工具导入时生成的**测试号**（`wx53ddd2f6a698c6ad`）。测试号适合开发，但**没有体验成员管理**，不能发给别人。
- 需要注册一个正式小程序（个人主体即可，免费）：
  1. 打开 <https://mp.weixin.qq.com/> → 立即注册 → 小程序
  2. 邮箱激活 → 主体类型选「个人」→ 身份证 + 人脸验证
  3. 注册完成后在「开发管理 → 开发设置」拿到 AppID
- 拿到 AppID 后告诉我，我改配置并重新上传；你也可以在开发者工具「详情 → 基本信息」里直接改。

## 步骤（有正式 AppID 后）

### 1. 上传代码

```bash
# 在项目的上一级目录执行（开发者工具安装路径按实际调整）
"C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload \
  --project "C:\Users\arrangle\Desktop\ganfan-radar" \
  -v 1.0.0 -d "农餐馆体验版"
```

上传成功后会出现在小程序后台的「版本管理 → 开发版本」。

### 2. 添加体验成员

1. 登录 <https://mp.weixin.qq.com/>，进入你的小程序
2. 左侧「管理」→「成员管理」→「体验成员」
3. 添加朋友的微信号，或生成邀请二维码让朋友自己扫码加入
4. 个人主体体验成员上限 **15 人**（企业主体更多）

### 3. 设为体验版

1. 左侧「管理」→「版本管理」
2. 在「开发版本」里找到刚上传的版本 → 点「选为体验版」
3. 在体验版区域生成**体验版二维码**

### 4. 发给朋友

- 把体验版二维码发给朋友，他们用被你添加的微信号扫码即可打开
- 也可以在小程序里用「分享给朋友」转发卡片（卡片只对体验成员有效）
- 体验版**不需要审核**，改完重新上传再选为体验版即可

## 朋友打开后连不上数据？

体验版默认连的服务器地址需要在小程序里设置：

1. 首页右上角 ⚙
2. 填公网地址（例如 `https://你的域名` 或临时隧道地址）
3. 正式环境必须 HTTPS + 已备案域名，并在小程序后台配置 request 合法域名

比赛演示阶段可以先用「手机热点 + 局域网 IP」或临时 HTTPS 隧道，并让对方在微信里打开调试模式。

## 如果只是想尽快让人看到

- **网页版**：直接发公网链接，任何人浏览器可开，无需登录
- **小程序**：需要上面的正式 AppID + 体验成员，至少 30 分钟注册时间
- 两条路径不冲突，网页链接可以先发
