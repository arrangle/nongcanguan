# 发布体验版与域名配置

小程序和网页不一样：**预览二维码只有开发者本人能扫**。要让别人在自己微信里打开，必须走「体验版 + 体验成员」。

先说三条绕不过去的规则，后面所有步骤都是围绕它们：

1. **体验版不需要审核**。上传代码 → 后台「选为体验版」→ 加体验成员 → 发二维码，10 分钟能跑通。
2. **真机默认只允许请求「已在小程序后台配置过的 HTTPS 域名」**，其他地址一律被拦。
3. **合法域名必须是你自己的、已 ICP 备案的域名，走 443，不能带端口和路径**。

所以出现两种做法：

| 方案 | 能做什么 | 时间 | 适用 |
|---|---|---|---|
| A. 体验版 + 手机「打开调试」 | 绕开域名校验，直连公网 IP:3000 或临时 HTTPS 隧道 | 今天就能用 | **决赛现场演示** |
| B. 自有域名 + 备案 + HTTPS | 正式合法域名，不用开调试 | 备案通常 5–20 个工作日 | 赛后长期运营 |

## 二、方案 A：决赛前不买域名怎么让手机连上数据

体验版默认连 `miniprogram/config.js` 里的 `BASE_URL`。当前填的是线上隧道地址。真机第一次打开大概率会提示「加载失败」，因为域名没备案、也没在后台配置——用「打开调试」绕过去：

### 1. 手机上打开调试模式

1. 微信里打开体验版小程序
2. 右上角「…」→「开发调试」→「打开调试」
3. 小程序会重启，右上角出现绿色的「vConsole」按钮，说明已进入调试模式
4. 这时 **不校验合法域名、TLS 版本和 HTTPS 证书**，`http://IP:端口` 也能请求

> 每个体验成员都要各自开一次；关掉小程序再进来依然生效。

### 2. 填服务器地址

在体验版首页右上角 **⚙** 里填下面之一（保存后立即生效）：

- 临时隧道（当前可用）：`https://exports-getting-participant-parameters.trycloudflare.com`
- 公网 IP：`http://62.234.118.40:3000` —— **需要先在腾讯云轻量云控制台「防火墙」放行 TCP 3000**，现在只放行了 80/443/8888/3389

### 3. 这个方案的限制（如实说明）

- 隧道域名是临时的，服务器上的 cloudflared 进程重启就会换一个，换完要重新填地址
- 调试模式只对开发版 / 体验版有效，**正式发布后必须走方案 B**
- 队外的人（评委、同学）如果不是体验成员，打不开体验版；让他们看网页版更省事

## 三、方案 B：配一个正式域名（一劳永逸）

以下以腾讯云为例，域名示例 `api.nongcanguan.cn`、服务器 `62.234.118.40`。

### 1. 买域名并实名

1. 腾讯云控制台 →「域名注册」→ 买一个 `.cn` / `.com`（几元到几十元/年）
2. 同账号做**域名实名认证**（上传身份证，通常几小时到 1 个工作日）
3. 域名持有者建议与备案主体一致（个人就是本人）

### 2. ICP 备案（境内服务器必须）

境内轻量云服务器，**域名不备案，80/443 会被拦**，Nginx 配好也访问不了。

1. 腾讯云控制台 →「备案」→ 开始备案
2. 轻量应用服务器需先申请**备案服务号**（套餐剩余时长一般要 ≥3 个月，控制台里能看到「申请备案服务号」）
3. 按向导填写：主体信息 → 网站信息（网站名称、服务内容选「其他」或「生活服务」）→ 上传证件 → 人脸核验
4. 腾讯云初审（1–2 天）→ 管局审核（通常 3–15 个工作日）
5. 通过后会收到备案号，域名才能解析到境内服务器对外提供 80/443 服务

> 时间不可控，**决赛前（11-29）基本来不及**，所以决赛用方案 A，备案可以同时提交、赛后启用。

### 3. 域名解析

腾讯云 →「DNSPod / 域名解析」→ 添加记录：

| 主机记录 | 类型 | 记录值 | TTL |
|---|---|---|---|
| api | A | 62.234.118.40 | 600 |

`ping api.你的域名` 能解析到服务器 IP 即生效。

### 4. 服务器：Nginx 反代 + 证书

应用现在监听 `127.0.0.1:3000`（systemd 服务 `nongcanguan`），前面挂 Nginx 处理 443：

```bash
sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx
```

新建 `/etc/nginx/sites-available/nongcanguan`：

```nginx
server {
    listen 80;
    server_name api.nongcanguan.cn;

    location / {
        return 301 https://$host$request_uri;
    }
}

server {
    listen 443 ssl http2;
    server_name api.nongcanguan.cn;

    # certbot 会自动改写这两个路径
    ssl_certificate     /etc/letsencrypt/live/api.nongcanguan.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.nongcanguan.cn/privkey.pem;

    client_max_body_size 1m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并申请证书：

```bash
sudo ln -s /etc/nginx/sites-available/nongcanguan /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 首次申请（需要 80 端口可访问、域名已解析）
sudo certbot --nginx -d api.nongcanguan.cn
# 自动续期
sudo systemctl list-timers | grep certbot
```

验证：

```bash
curl -s https://api.nongcanguan.cn/api/health
# {"ok":true,...}
```

> 也可以不用 certbot，在腾讯云「SSL 证书」申请免费证书，下载 Nginx 版后把 `ssl_certificate` 指向证书文件。
> 证书到期前 certbot 会自动续期；用腾讯云证书则要记得手动换。

### 5. 小程序后台配置合法域名

1. <https://mp.weixin.qq.com/> →「开发管理」→「开发设置」→「服务器域名」
2. 「request 合法域名」填：`https://api.nongcanguan.cn`
3. 保存（**每月只能改 5 次**，想好再填）

注意：

- 只能填域名，**不能带端口、路径、通配符**
- 必须是 HTTPS，且证书有效
- 改完需要在小程序里「重新进入」才生效，必要时清一次缓存

### 6. 改配置、重新上传

1. `miniprogram/config.js` 的 `BASE_URL` 改成 `https://api.nongcanguan.cn`
2. 重新 `cli upload`，后台再「选为体验版」
3. 手机上直接在体验版里打开，**不需要再开调试模式**

### 7. 最后才谈正式发布

体验版验证没问题后，在后台「版本管理 → 提交审核」，审核通过再「发布」。审核只针对已发布版本，体验版不受影响。

## 五、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 体验版打开是白屏 / 加载失败 | 域名没配置且没开调试 | 打开调试模式，或配置合法域名 |
| 「request 域名不合法」 | 域名没在后台配置 | 开发设置里添加该域名 |
| 配置了域名还是不合法 | 域名没备案 / 证书过期 / 带端口 | 备案 + 换有效证书 + 去掉端口 |
| 改完域名没生效 | 小程序缓存 | 杀掉小程序重进，或清缓存 |
| 隧道地址过几天失效 | cloudflared 临时隧道重启换域名 | 填新地址；长期使用配命名隧道或自有域名 |
| 后台提示域名修改次数用尽 | 每月 5 次 | 等下月，或用子域名 |
| 手机 4G 打开失败 | 服务器只监听了 127.0.0.1 / 防火墙没开 | Nginx 反代 443，或放行 3000 |
